# Google Loading Animation

A lightweight recreation of the Google-style loading animation built using plain HTML, CSS and a touch of JavaScript.

![Preview](./Screenshot%202024-07-02%20191157.png)

## Overview

This repository demonstrates a simple, responsive, and easy-to-follow animation inspired by Google's loading indicator. It's ideal as a learning reference for CSS animations and transforms or as a small UI enhancement you can drop into projects.

## Features

- Smooth, looped loading animation
- Built with only HTML, CSS and a small JavaScript routine
- Small footprint and easy to customize (colors, speed, size)

## Demo

1. Clone this repository:

   git clone https://github.com/BinaryVortex/Google-Loading-Animation.git

2. Open `index.html` in your browser:

   - Double-click the file or serve the folder with a static server (e.g., `npx http-server` or `python -m http.server`).

The animation should run automatically.

## Files

- `index.html` — markup for the animation
- `style.css` — styles and animation keyframes

## Customization

- Colors: edit the CSS variables or color declarations in `style.css`.
- Speed: adjust animation-duration values in `style.css`.
- Size: change container dimensions or scale transforms.
